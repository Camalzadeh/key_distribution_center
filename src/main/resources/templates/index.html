Key distribution

Messages nobody in the middle can read

Every account gets an RSA key pair. A message is enciphered with a symmetric key you choose, and that key is then wrapped with the recipient's public key — so the key travels with the message and only its owner can unwrap it.

Sign in to see your key pair

One form does both: a username that does not exist yet is registered, and its key pair is generated on the spot.
